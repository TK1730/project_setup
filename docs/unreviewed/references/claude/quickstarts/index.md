# Claude Quickstarts

- [autonomous-coding の要約](autonomous-coding.md) - Anthropic の claude-quickstarts リポジトリにある autonomous-coding の要約で、初期化エージェントとコーディングエージェントの 2 段構成で、何セッションもかけてアプリを作らせる最小のハーネスの仕組みと、Bash コマンドを許可リストで絞る安全対策を説明する。
- [autonomous-coding のコーディング用プロンプト](autonomous-coding-coding-prompt.md) - claude-quickstarts の autonomous-coding で、2 回目以降の毎セッションに送るプロンプト coding_prompt.md の要約で、記憶のない状態から状況をつかみ、1 機能を実装してブラウザで確かめ、きれいな状態で終えるまでの 10 段階の手順と、その書き方の工夫を説明する。
