# 依頼の書き方の改善（逆質問の集計）

AI から逆質問された記録を集計し、依頼に欠けやすい指標を見つける仕組みの使い方。良くする対象は AI ではなく、人が書く依頼の型である。

## 仕組みの流れ

1. AI は、依頼に足りない情報を逆質問したときに、`gate-events.jsonl` に 1 行記録する。これは AGENTS.md の規定による。
1. 週に 1 回、集計スクリプトを実行し、どの指標が欠けやすいかを見る。
1. 欠けやすい指標を書き忘れないように、自分の依頼の型を直す。
1. 次の週の集計で、その指標の件数が減ったかを確かめる。

## 記録の場所と形

記録は `~/.antigravity-gate/gate-events.jsonl` にある。このディレクトリが無ければ `~/.claude-gate/gate-events.jsonl` を使う。1 行が 1 件の逆質問である。

```text
{"ts": "2026-10-19T10:00:00+09:00", "type": "clarify", "missing": ["目的・Done", "検証"], "summary": "依頼の要約"}
```

`missing` には、次の 4 つの指標名だけを書く。

| 指標名       | 意味                                               |
| :----------- | :------------------------------------------------- |
| `目的・Done` | 何ができたら完了か                                 |
| `制約`       | バージョン、触ってよい範囲、既存資産の利用可否など |
| `文脈`       | 対象のファイル、入出力の例、エラーログなど         |
| `検証`       | どう確かめるか（テスト、画面、コマンド）           |

## 集計の実行

リポジトリのルートで実行する。外部ライブラリは使わない。

```bash
python3 scripts/harness/clarify_report.py
```

出力は次の 3 つである。

- 逆質問の件数
- 指標ごとの件数と割合。1 件の逆質問に複数の指標が入ることがあるので、割合の合計は 100% を超える。
- 週ごとの件数。週は ISO 週（例: `2026-W42`）で数える。

4 つの指標名に揃えられない名前があると、最後に「揃えられなかった指標名」として表示する。その名前が 4 つのどれかに当たるなら、スクリプトの `normalize` に揃え方を足す。

## 結果の読み方

- 割合が高い指標が、依頼で書き忘れやすい指標である。依頼の型を直すときは、割合の高い指標から 1 つずつ手を付ける。
- 推移を見るときは、件数そのものより、指標ごとの増減を見る。依頼の数が多い週は、逆質問の件数も増えるためである。
- 依頼の型を直した週を記録しておくと、その前後で件数を比べられる。

## 決定理由（Rationale）

- 確かめ方を「同じ依頼で前後を比べる」にしなかった。良くしたいのは人の依頼の書き方なので、AI に同じ依頼を 2 回実行させても比べるものがないためである。
- 過去の記録は書き換えず、読み込むときに表記ゆれを揃える。元の記録を残しておけば、揃え方が間違っていたときにやり直せるためである。
- スクリプトは shell ではなく Python で書いた。JSON の読み込み、表記ゆれの揃え、週ごとの集計といったデータの加工が中心のためである。
