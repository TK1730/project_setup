# ハーネス改善の仕組み

AI と開発するときのやり方を、記録をもとに少しずつ良くしていく仕組み。目的ごとに仕組みを分けている。どの仕組みも、改善案を出すところまでを自動にし、採用するかは人が決める。

- [依頼の書き方の改善（逆質問の集計）](prompt-quality.md) - AI から逆質問された記録を集計し、依頼に欠けやすい指標を見つけて依頼の書き方を良くする仕組みの使い方。
- [同じミスの再発防止（mistake-retro）](mistake-retro.md) - AI が指摘されたミスを過去の記録と照らし合わせ、ハーネスへの改善案を出すスキル mistake-retro の使い方。
- [ハーネスの前後比較（probe.sh）](probe.md) - 同じ確認用の依頼を変更前と変更後のハーネスで実行し、結果を並べて保存するスクリプト probe.sh の使い方。
- [docs の機械チェック（docs_check.py）](docs-check.md) - docs の決まりのうち機械的に判定できるものを確かめるスクリプト docs_check.py の使い方。
- [作業の質の振り返り（work-retro）](work-retro.md) - coding や docs の変更の質を振り返り、作業のルールへの改善案を出すスキル work-retro の使い方。
