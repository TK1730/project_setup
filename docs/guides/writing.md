# 文章の書き方

文書の中の文章をどう書くかのルール。読者は読むより流し読みするので、要点がすぐ拾える文章にする。

## ルール

- 結論・要約を先に書く（BLUF）。節の中でも、要点を先頭の文に置く。
- 曖昧な表現を避け、誰が読んでも一意に解釈できるように書く。
- 専門用語や略語には、必要に応じて注釈を添える。
- 製品名やツール名は、元の大文字小文字のまま書く（`GitHub`、`PostgreSQL` など）。
- 簡潔に書く。読者が必要とするのは、書き手の知識のごく一部である。
